# ACCTA Business Suite — Releases

This repository hosts official MSI installer releases for ACCTA Business Suite.

## Downloads

Download the MSI installer from the [Releases page](https://github.com/AlainMagellan/ACCTA-Releases/releases).

## Installation

Run the downloaded MSI installer and follow the Windows Installer instructions.

## Licence

ACCTA Business Suite licence requirements continue to apply after installation and upgrades.

## Data protection

Back up your business data before installing an upgrade.
